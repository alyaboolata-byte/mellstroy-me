# Mellstroy.me

Отдельный сайт о Mellstroy Casino: вход, регистрация, зеркало, казино, игры, платежи, мобильная версия и бонусные предложения. Семнадцать языков: RU, PL, EN, PT, UK, HI, UZ, KK, TG, DE, IT, ES, TR, AZ, HY, RO-MD и FR.

## Где менять сайт через GitHub

Открой репозиторий, выбери файл, нажми значок карандаша **Edit**, внеси правку и нажми **Commit changes** в ветку `main`.

- `site-config.mjs` → `DESTINATION_URL`: одна внешняя ссылка для всех кнопок и языков. Здесь же список `OFFERS`: проценты, FS, порядок и изображения. Меняй бонусные цифры только после проверки актуальных условий.
- `content.mjs` и `extra-locales.mjs` → заголовки, SEO-описания, FAQ и интентные тексты для всех 17 языков.
- `offer-content.mjs` → локализованные названия бонусных предложений.
- `styles.css` → цвета, отступы, баннеры, мобильный дизайн.
- `assets/` → изображения и `favicon.webp`.

Для изменения ссылки на всех кнопках достаточно **одной строки** в `site-config.mjs`. Ссылка из предыдущего состояния этого репозитория сохранена как временная — перепроверь её перед запуском трафика. Не меняй сгенерированную папку `dist`: Vercel создаёт её при сборке.

## Проверка локально

```sh
npm run check
npm run verify
```

Проект статический, зависимости не нужны. Vercel должен быть подключён к **этому** GitHub-репозиторию, ветка `main`, команда сборки `npm run build`, директория вывода `dist`. После коммита проверь новый deployment и страницу сайта. Наличие исходников в GitHub само по себе не доказывает, что Vercel настроен на автоматическое развёртывание.

Сборка создаёт 357 HTML-страниц, `robots.txt` и `sitemap.xml`; canonical, 17 взаимных hreflang, x-default и lastmod формируются из одного списка. Microsoft Clarity подключён отдельным проектом `z4hsgdjk7o`.

Баннеры были утверждены как **дизайн-макеты**. Перед публикацией точных бонусных обещаний подтвердите проценты, FS, географию и условия у оператора.

## Переобход

После успешной публикации и проверки домена: `npm run build && node submit-indexnow.mjs`. Скрипт проверяет публичный ключ и отправляет все 357 URL из текущей сборки в IndexNow. Приём запроса не подтверждает индексацию. Google и Bing принимают `https://mellstroy.me/sitemap.xml` отдельно в кабинетах вебмастеров.

Бонусные баннеры отображаются целиком в горизонтальном ряду с прокруткой. Каждый баннер — прямая ссылка на `DESTINATION_URL`, без промежуточной страницы, HTML-подписи или дублирования процентов. Текст внутри оригинального изображения остаётся частью изображения. Страницы `/bonus/…/` сохранены с полным баннером для существующих ссылок.
